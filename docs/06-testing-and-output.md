# 基于大模型的文档智能写作助手：测试与文档输出完善

## 1. 阶段目标

本阶段对已经完成的后端与前端功能进行集中验证，并完善文档导出效果。测试重点包括系统接口闭环、前端资源加载、正文保存、文本修订、Word 导出、文本导出和导出文件结构检查。

## 2. 文档输出完善

已对 `backend/app/exporter/document_exporter.py` 进行完善，当前导出文件具备以下结构：

1. 文档标题。
2. 文体、目标字数、写作风格等元信息。
3. 写作提纲。
4. 正文。
5. 摘要。
6. 页脚标识。
7. 实际字数信息。

Word 导出样式采用正式文档风格：

| 项目 | 设置 |
| --- | --- |
| 页边距 | 上、下、左、右均为 1 英寸 |
| 正文字号 | 11 pt |
| 中文字体 | Microsoft YaHei |
| 英文字体 | Calibri |
| 一级标题 | 16 pt，蓝色层级 |
| 二级标题 | 13 pt，蓝色层级 |
| 行距 | 约 1.1 倍 |
| 导出格式 | `.docx`、`.txt` |
| 字数控制 | 正文生成后控制在目标字数 ±10% 范围内 |

导出时还会返回文件名、路径和文件大小，便于前端下载和测试记录。

## 3. 测试脚本

当前测试脚本位于：

```text
backend/tests/
  http_smoke_test.py
  export_structure_test.py
  word_count_test.py
  run_all.py
```

脚本说明：

| 脚本 | 作用 |
| --- | --- |
| `http_smoke_test.py` | 验证前端首页、前端脚本、健康检查、完整生成、正文保存、润色和 Word 导出 |
| `export_structure_test.py` | 验证 Word 和文本导出结构、文件存在性、文件大小、页边距和字体设置 |
| `word_count_test.py` | 验证 500、800、1200 字目标下的正文实际字数是否在 ±10% 范围内 |
| `run_all.py` | 顺序运行全部测试 |
