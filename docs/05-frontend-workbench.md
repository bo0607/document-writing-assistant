# 基于大模型的文档智能写作助手：前端写作工作台实现

## 1. 阶段目标

本阶段完成前端写作工作台，实现用户可直接操作的文档生成界面。前端不引入 npm 构建工具，采用原生 HTML、CSS 和 JavaScript 实现，并由现有 Python 后端直接托管。

用户启动后端后，访问以下地址即可进入系统：

```text
http://127.0.0.1:8000/
```

## 2. 前端文件

前端文件位于：

```text
backend/static/
  index.html
  styles.css
  app.js
```

文件职责：

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构 |
| `styles.css` | 工作台视觉样式和响应式布局 |
| `app.js` | 前端状态管理、接口调用和页面渲染 |

## 3. 页面结构

前端采用三栏工作台结构：

| 区域 | 功能 |
| --- | --- |
| 左侧写作要求区 | 输入主题、文体、字数、风格、补充要求，查看最近任务 |
| 中间写作内容区 | 展示提纲、正文，并支持编辑正文 |
| 右侧文本处理区 | 选择修订方式、填写修订要求、生成摘要、导出文件 |

该结构与前面架构设计中的“前端写作工作台”保持一致，避免做成普通聊天页面或通用智能体控制台。

## 4. 已实现功能

当前前端已实现：

1. 后端状态检测。
2. 一键生成文档。
3. 展示生成提纲。
4. 展示并编辑正文。
5. 保存手动修改后的正文。
6. 润色、改写、扩写、缩写、纠错和自定义修订。
7. 生成摘要。
8. 导出 Word 文档。
9. 导出文本文件。
10. 查看并载入最近任务。

## 5. 接口对接

前端已对接以下后端接口：

| 接口 | 用途 |
| --- | --- |
| `/api/health` | 检查后端状态 |
| `/api/tasks` | 加载最近任务 |
| `/api/task/detail` | 载入任务详情 |
| `/api/task/run-full` | 一键生成提纲和正文 |
| `/api/draft/update` | 保存正文编辑结果 |
| `/api/text/revise` | 执行润色、改写、扩写等修订 |
| `/api/text/summary` | 生成摘要 |
| `/api/document/export` | 导出 Word 或文本 |
| `/exports/<fileName>` | 下载导出文件 |

## 6. 后端托管调整

为了让系统运行更简单，已在 `backend/app/main.py` 中增加静态资源托管：

1. `/` 和 `/index.html` 返回前端首页。
2. `/static/...` 返回 CSS 和 JavaScript 文件。
3. `/exports/...` 返回导出的文档文件。

这样用户不需要单独启动前端开发服务器，只需要启动后端即可同时访问页面和接口。
